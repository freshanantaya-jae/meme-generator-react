# Meme Studio — React Vibe Coding Exercise

A small Imgflip-inspired meme/poster editor built with React + Vite.

## Features
- Upload your own image
- Built-in starter templates
- Multiple draggable text layers
- Font, size, color, alignment, opacity and outline controls
- Emoji/sticker layers
- Layer selection, reorder, duplicate and delete
- Grayscale, brightness, contrast and blur
- Undo / redo
- Save/load project state with localStorage
- Export PNG
- Export PDF

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Notes
The starter template images use remote Unsplash URLs. For a fully offline project, replace them with local images in `public/`.
